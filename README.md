# 史镜 · 你最像哪个历史人物

一个纯前端、娱乐向的历史人物性格测试。12 道情境题 → 9 维性格向量 → 在 636 位历史人物里找出最像你的那一位，生成 3D 收藏卡，并一键跳转维基百科。

> 本项目仅供娱乐，人物的性格数值是主观设定，不是史学结论，更不是心理测评。
> 交互框架 fork 自 [scarea/sbti](https://github.com/scarea/sbti)（程序员馊味人格测试），本仓库是独立的新项目。

## 功能

- **636 位人物**：中国帝王 219（先秦君主到清帝、五代十国、辽金元、太平天国等）、外国君主 74、政要首脑 58（美国历任总统、各国领袖等）、思想文学 92、科学艺术 83、将帅谋臣 110
- **12 道随机题**（题库 36 题）：每题 4 个选项，顺序随机；选完弹出一句即时点评
- **9 维性格**：野心 · 谋略 · 勇武 · 铁腕 · 仁德 · 才情 · 变革 · 洒脱 · 隐忍
- **结果页**：3D 收藏卡（拖动旋转、点击翻面、背面看雷达）、契合度、「你们最像的地方 / 不同的地方」、你与 TA 的雷达叠加、相似人物 Top 6
- **维基百科**：每张卡都有「在维基百科阅读 ↗」；简介由前端实时从中文维基取回（带 CC BY-SA 署名）；肖像来自维基缩略图，无肖像的用印章占位
- **人物图鉴**：按地区 / 分类筛选、关键词搜索、分页加载、测过的人物会被点亮收藏
- **今日人物**：按日期固定的每日一位，可换一个
- **分享**：1080×1920 海报（canvas 导出）；挑战链接 `?f=<id>`，朋友打开后测完能看到两人的契合度
- 明暗主题（墨色 / 宣纸）、`prefers-reduced-motion`、移动端适配

## 计分原理

1. 每题每个维度先算「随机作答」的期望和方差，把得分换算成偏离随机的程度（z 分数）。
2. 每个人物的 9 维向量（0–9）先减去自己的均值（只比较「性格形状」，否则全面型帝王永远匹配不到），再减去全体人物的平均形状，单位化。
3. 用户 z 向量与人物向量做余弦相似度，加上校准偏置，取最高分；契合度百分比由分数线性映射，仅用于展示。
4. `scripts/calibrate.mjs` 做蒙特卡洛模拟，调整每个人物的偏置，让随机作答下 636 人都能被命中、且分布尽量均匀。

## 增删人物

编辑 `scripts/source/*.txt`，格式：

```text
显示名 [副标题]|维基词条(空=显示名)|朝代或国家|生卒|一句话|9位向量
```

向量顺序固定为 `野 谋 武 铁 仁 才 革 逸 忍`，每位 0–9，例如 `987924926`。文件里用 `#E cn`、`#S wd` 这类行切换分类与地区：

| 分类 | 含义 | 地区 |
| --- | --- | --- |
| E | 中国帝王 | cn 中国 |
| R | 外国君主 | wd 世界 |
| P | 政要首脑 | |
| S | 思想文学 | |
| K | 科学艺术 | |
| G | 将帅谋臣 | |

然后依次运行：

```bash
node scripts/build-figures.mjs   # 联网：校验词条是否存在 / 是否落到消歧义页，抓取肖像；结果缓存在 scripts/.wiki-cache.json
node scripts/calibrate.mjs --write
node scripts/stamp.mjs
```

`build-figures` 遇到「词条不存在 / 消歧义页」会报错并列出人物，把第 2 个字段改成正确的维基标题（如 `石虎 (后赵)`）再跑即可。维基 API 有限流，脚本已做退避重试。`--refresh` 强制重抓，`--offline` 只用缓存。

> 人物 id 是源文件里的先后顺序，所以新人物尽量追加在文件末尾，否则已发出去的分享链接会指向别的人。改完顺序后务必重新跑 `calibrate`。

## 改题库

编辑 `data/questions.js`，每题恰好 4 个选项，每个选项的 `score` 总和为 3：

```js
{ title: "选项文字", quip: "选中后的点评", score: { Y: 2, M: 1 } }
```

维度键：`Y` 野心 `M` 谋略 `W` 勇武 `T` 铁腕 `R` 仁德 `C` 才情 `G` 变革 `D` 洒脱 `N` 隐忍。改完重新跑 `node scripts/calibrate.mjs --write`。

## 本地运行

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765
```

或双击 `start.command`。直接双击 `index.html`（`file://`）也能看，但海报导出会被浏览器禁止。

## 部署

纯静态站点，无需构建。把 `index.html`、`css/`、`js/`、`data/` 部署到 GitHub Pages / Vercel / Netlify / Cloudflare Pages 等任意静态托管即可。发布前运行一次 `node scripts/stamp.mjs`。
